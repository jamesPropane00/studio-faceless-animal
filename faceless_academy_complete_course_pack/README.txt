FACELESS ACADEMY COURSE PACK

FILES
- courses.html: optional library/catalog page
- Every other HTML file is a standalone course and can be attached to your existing main site.
- Each course contains embedded CSS and JavaScript, so there are no required dependency folders.

INSTALL
1. Upload the HTML files to the same public folder.
2. Link your existing course cards to the desired filename.
3. Inside each course, the "Course Library" button points to courses.html.
4. OpenCode can change that href to your existing main course URL.

IMPORTANT
- Practice questions are original and objective-aligned, not copied or leaked exam questions.
- No course can guarantee a pass.
- Always verify current official exam objectives before scheduling.
- Progress is stored in the browser with localStorage.
