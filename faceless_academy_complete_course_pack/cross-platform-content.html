1. Content architecture

Turn one core idea into platform-native assets.

Core knowledge

  • Start with one strong subject or story.
  • Create a long-form master when the topic supports depth.
  • Extract short hooks without removing necessary context.
  • Rewrite packaging for each platform.

2. Rights and source files

Keep ownership and evidence organized.

Core knowledge

  • Save clean masters without platform watermarks.
  • Track music, footage, image, and license rights.
  • Maintain captions and project files.
  • Check each platform's current reused-content and licensing rules.

3. Publishing workflow

Use a controlled calendar.

Core knowledge

  • Batch editing and scheduling reduce wasted effort.
  • Do not post identical captions everywhere without adaptation.
  • Track each upload URL and result.
  • Update the next batch based on evidence.

4. Measurement

Compare like with like.

Core knowledge

  • Separate short-form and long-form analysis.
  • Use retention, click behavior, watch time, search, and return behavior.
  • Do not compare raw views across platforms as though distribution is identical.
  • Record hypotheses before changing strategy.
