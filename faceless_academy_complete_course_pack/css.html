1. Cascade and specificity

Predict which declaration wins.

Core knowledge

  • Origin, importance, cascade layers, specificity, scoping proximity, and source order affect results.
  • IDs are more specific than classes.
  • Avoid excessive !important.
  • Inheritance applies only to certain properties.

2. Box model

Calculate element sizing.

Core knowledge

  • Content box is the default sizing model.
  • border-box includes padding and border within declared width.
  • Margins are outside the border.
  • Vertical margins can collapse in normal block flow.
* { box-sizing:border-box; }

3. Layout

Choose Grid, Flexbox, or normal flow.

Core knowledge

  • Flexbox excels in one dimension.
  • Grid controls two dimensions.
  • position:absolute removes an element from normal flow.
  • Sticky positioning depends on a scroll container and inset.

4. Responsive CSS

Adapt without fragile device assumptions.

Core knowledge

  • Use fluid sizing and flexible layouts.
  • Media queries respond to conditions.
  • Container queries respond to container size.
  • Use responsive images where appropriate.

5. Accessibility and performance

Avoid styling that harms usability.

Core knowledge

  • Maintain contrast.
  • Do not remove focus indicators without replacement.
  • Respect prefers-reduced-motion.
  • Avoid layout-thrashing patterns and oversized CSS.

Practice Exam

These are original exam-style questions, not copied test items.

1. Which selector is most specific?

An ID selector has higher specificity than a class or element.

2. What does box-sizing:border-box change?

It makes sizing more predictable.

3. Which system is ideal for two dimensions?

Grid handles rows and columns.

4. Which property makes keyboard focus visible?

Outline is commonly used for focus indication.

5. Which media feature supports motion sensitivity?

It lets authors reduce animation.
