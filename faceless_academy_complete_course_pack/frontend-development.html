1. Web foundations

Understand how browser-based applications are structured.

Core knowledge

  • Semantic HTML improves accessibility and meaning.
  • CSS controls presentation; JavaScript controls behavior.
  • The DOM represents the page as objects.
  • HTTP requests connect the frontend to servers.
<button id='save'>Save</button>

2. HTML and accessibility

Build meaningful, usable markup.

Core knowledge

  • Use headings in logical order.
  • Associate labels with form controls.
  • Use buttons for actions and links for navigation.
  • Provide useful alt text for informative images.
<label for="email">Email</label>
<input id="email" type="email">

3. CSS layout

Build reliable responsive layouts.

Core knowledge

  • Flexbox is primarily one-dimensional.
  • Grid handles rows and columns.
  • Use box-sizing:border-box for predictable sizing.
  • Media queries adapt layouts to viewport conditions.
.grid { display:grid; grid-template-columns:repeat(auto-fit,minmax(240px,1fr)); }

4. JavaScript and DOM

Add interaction safely.

Core knowledge

  • querySelector selects the first matching element.
  • addEventListener registers event handlers.
  • Avoid unsanitized innerHTML with untrusted input.
  • Async work commonly uses promises and async/await.
document.querySelector('button').addEventListener('click', handleClick);

5. Performance and testing

Reason about real production frontends.

Core knowledge

  • Lazy-load noncritical assets.
  • Minimize layout shifts.
  • Test keyboard navigation.
  • Use browser developer tools to inspect network and console errors.

Practice Exam

These are original exam-style questions, not copied test items.

1. Which element should trigger a form submission?

A native submit button provides correct behavior and accessibility.

2. Which layout tool is strongest for rows and columns together?

CSS Grid is designed for two-dimensional layout.

3. What is the safest default for displaying untrusted text?

textContent does not parse the value as HTML.

4. What does HTTP 404 normally mean?

404 indicates the requested resource was not found.

5. Which attribute connects a label to an input?

The label for value matches the input id.
