1. Docker foundations

Understand images, containers, registries, and Dockerfiles.

Core knowledge

  • An image is an immutable template.
  • A container is a running or stopped image instance.
  • A registry stores images.
  • Layers improve reuse and caching.
docker run --rm hello-world

2. Dockerfiles

Build reproducible images.

Core knowledge

  • FROM selects the base image.
  • WORKDIR sets the working directory.
  • COPY adds files.
  • RUN executes at build time; CMD supplies a default runtime command.
FROM python:3.12-slim
WORKDIR /app
COPY . .
CMD ["python","app.py"]

3. Container operations

Inspect and control containers.

Core knowledge

  • docker ps lists running containers.
  • docker logs reads output.
  • docker exec runs a command inside a running container.
  • Port mapping uses host:container.
docker run -p 8080:80 myapp

4. Git with Docker

Use version control without committing generated or secret files.

Core knowledge

  • Commit Dockerfile and compose configuration.
  • Use .dockerignore to reduce build context.
  • Do not commit secrets or environment files.
  • Tag images with meaningful versions or commit identifiers.
.env
node_modules/
.git/

5. Compose and troubleshooting

Run multi-container systems.

Core knowledge

  • Compose defines services, networks, and volumes.
  • Volumes persist data beyond a container lifecycle.
  • Check logs before rebuilding blindly.
  • Bind mounts are useful during development.
docker compose up --build
