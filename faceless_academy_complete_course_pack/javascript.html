1. Language fundamentals

Master types, scope, equality, and control flow.

Core knowledge

  • let and const are block-scoped.
  • === avoids implicit type coercion.
  • Objects are reference values.
  • Falsy values include false, 0, empty string, null, undefined, and NaN.
const total = items.reduce((sum,item)=>sum+item.price,0);

2. Functions and closures

Understand execution and retained scope.

Core knowledge

  • Functions are first-class values.
  • A closure retains access to its lexical environment.
  • Arrow functions do not bind their own this.
  • Default parameters run when an argument is undefined.
function counter(){ let n=0; return ()=>++n; }

3. Arrays and objects

Transform collections cleanly.

Core knowledge

  • map transforms each item.
  • filter selects items.
  • reduce accumulates one result.
  • Spread syntax creates shallow copies.
const active = users.filter(u => u.active).map(u => u.name);

4. Async JavaScript

Handle operations that finish later.

Core knowledge

  • Promises have pending, fulfilled, or rejected states.
  • await pauses inside an async function.
  • Use try/catch around awaited failures.
  • Promise.all rejects if one included promise rejects.
async function load(){ try { return await fetch('/api'); } catch(e){ console.error(e); } }

5. Debugging

Identify common runtime and logic errors.

Core knowledge

  • Read stack traces from the first relevant application frame.
  • Use strict equality where type coercion is unwanted.
  • Check undefined before accessing nested values.
  • Optional chaining safely stops on nullish values.
const city = user?.address?.city ?? 'Unknown';
