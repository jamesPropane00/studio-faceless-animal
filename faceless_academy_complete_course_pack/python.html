1. Core syntax and types

Use Python collections, expressions, and control flow.

Core knowledge

  • Lists are mutable; tuples are immutable.
  • Dictionaries map hashable keys to values.
  • Indentation defines blocks.
  • is checks identity; == checks value equality.
counts = {word: words.count(word) for word in set(words)}

2. Functions and scope

Write reusable, predictable functions.

Core knowledge

  • Default mutable arguments can retain state across calls.
  • *args gathers positional arguments.
  • **kwargs gathers keyword arguments.
  • LEGB describes name lookup.
def add_item(item, items=None):
    items = [] if items is None else items
    items.append(item)
    return items

3. Iteration and comprehensions

Process data idiomatically.

Core knowledge

  • Generators yield values lazily.
  • enumerate returns index-value pairs.
  • zip combines iterables.
  • Comprehensions build collections concisely.
squares = [n*n for n in range(10) if n % 2 == 0]

4. Exceptions and files

Handle errors and resources correctly.

Core knowledge

  • Catch specific exceptions.
  • finally runs whether an exception occurs or not.
  • with closes managed resources.
  • raise creates an exception.
with open('data.txt', encoding='utf-8') as f:
    text = f.read()

5. OOP and testing

Understand classes and verification.

Core knowledge

  • self refers to the instance.
  • Inheritance models an is-a relationship.
  • Composition is often preferred for flexible designs.
  • Unit tests should be deterministic and isolated.

1. Which collection stores key-value pairs?

A dict maps keys to values.

2. What does range(3) produce during iteration?

The stop value is exclusive.

3. Which statement safely opens and closes a file?

with uses a context manager.

4. What is the result of len({1,1,2})?

Sets contain unique values.

5. Which keyword produces values lazily?

yield turns the function into a generator.
