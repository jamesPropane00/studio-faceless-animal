1. Type system

Use static analysis to catch errors before runtime.

Core knowledge

  • TypeScript is a superset of JavaScript.
  • Type annotations are erased during compilation.
  • Type inference reduces unnecessary annotations.
  • any disables much type checking; unknown requires narrowing.
let count: number = 3;

2. Objects and unions

Model realistic data.

Core knowledge

  • Interfaces and type aliases describe shapes.
  • Union types represent alternatives.
  • Discriminated unions support safe branching.
  • Optional properties use ?.
type Result = {ok:true,data:string}|{ok:false,error:string};

3. Generics

Preserve type relationships.

Core knowledge

  • Generics parameterize types.
  • Constraints restrict allowed generic types.
  • Generic functions can retain input-output relationships.
  • Avoid using generics where a concrete type is clearer.
function first<T>(items:T[]):T|undefined { return items[0]; }

4. Narrowing

Prove a value's type.

Core knowledge

  • typeof narrows primitives.
  • in checks properties.
  • instanceof checks constructors.
  • Exhaustive checks help catch missing union cases.
if (typeof value === 'string') console.log(value.toUpperCase());

5. Configuration

Understand compilation choices.

Core knowledge

  • strict enables stronger checks.
  • target controls emitted JavaScript level.
  • module controls module output.
  • noImplicitAny reports inferred any parameters.
