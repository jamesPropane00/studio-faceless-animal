# RouteDrop — The Million-Car Route Network

RouteDrop is a mobile-first marketplace that helps people and businesses move small, ordinary items by matching requests with independent runners whose planned trips already pass near the pickup and destination.

**Core promise:** “Earn on the way. Send without the wait.”

This package contains:

- A working dependency-free HTML/CSS/JavaScript concept app
- Full product and business specification
- Nationwide growth strategy
- Legal and risk guardrails
- Technical architecture
- Supabase/Postgres schema starter
- API contract and event model
- Launch roadmap and implementation backlog
- Unit economics and marketplace liquidity plan

## Open the prototype
Open `app/index.html` in any browser. It uses mock information and stores new requests in localStorage.

## Recommended production stack

- Frontend: Next.js/React PWA or Vite React
- Backend: Supabase Auth, Postgres, Storage, Realtime, Edge Functions
- Maps: Mapbox or Google Maps
- Payments: Stripe Connect after counsel/insurance approval
- Notifications: email first; SMS/push later
- Analytics: privacy-conscious event analytics
- Hosting: Cloudflare Pages, Vercel, or Netlify

## Important
This is a product and engineering package, not legal advice. The first production release should remain local and intrastate in approved jurisdictions. State rules, insurance, worker classification, payment structure, and federal transportation rules require professional review before geographic expansion.
